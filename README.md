# Oriptos Social Engine — TikTok Hub & Automation

Official TikTok Content Posting API integration platform developed by Oriptos Ltd.

## Live Domain
- **URL:** [https://tiktok.oriptos.com](https://tiktok.oriptos.com)

## Features
- **TikTok OAuth Authentication:** Secure token exchange adhering to official scopes (`video.upload`, `video.publish`).
- **PandaPing & Broadcast Aesthetic:** Soft rounded corners (18px), Dark FinTech sidebar, clean white calendar & inbox views.
- **Bulk Queue & Calendar:** Visual multi-account scheduler for short-form video operations.
- **Direct Lead & Comment Handling:** In-app inbox interface for interacting with TikTok comments and followers.
- **Compliance & Legal Pages:**
  - Privacy Policy (`#privacy`)
  - Terms of Service (`#terms`)
  - User Data Deletion Instructions (`#data-deletion`)
